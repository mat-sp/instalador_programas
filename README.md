# Aula PC · Digitalización — GitHub Pages (versión 8)

Incluye el juego opcional Arcane Survivors.

1. Descomprime este ZIP.
2. Sube todo su contenido a la raíz de tu repositorio de GitHub, manteniendo las carpetas js, assets y vendor. index.html debe quedar en la raíz.
3. En Settings → Pages, selecciona Deploy from a branch, rama main y carpeta /(root). Pulsa Save.
4. GitHub mostrará en esa pantalla el enlace de la web cuando finalice la publicación.

Si actualizas un repositorio existente, sustituye los archivos y conserva esta estructura.

Para trasladar el progreso de la web anterior, pulsa Guardar en ella y Cargar en la nueva dirección.

No se necesita compilación, instalación de paquetes ni claves.
Las licencias de pdf-lib y las fuentes están incluidas en sus carpetas.
